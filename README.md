# 2048 Star Wars

A fan-made Star Wars edition of the 2048 sliding-tile puzzle. Eleven characters and ships, from a stormtrooper at 2 to the Death Star at 2048.

Una edición de Star Wars: once personajes y naves, del stormtrooper en el 2 al Death Star en el 2048.

**Play:** [English](https://tile2048.github.io/2048-STARWARS/) · [Español](https://tile2048.github.io/2048-STARWARS/es/)

## The ladder

| Value | Tile |
| ---: | --- |
| 2 | stormtrooper |
| 4 | super trooper |
| 8 | Darth Vader |
| 16 | TIE fighter |
| 32 | X-wing |
| 64 | Millennium Falcon |
| 128 | AT-AT all-terrain armored transport |
| 256 | C-3PO protocol droid |
| 512 | R2-D2 astromech droid |
| 1024 | Yoda |
| 2048 | Death Star |

## How to play

Arrow keys move the whole board; a swipe does the same on a phone. Two tiles of the same value merge into the next one on the ladder, and the value of the new tile is added to your score. The run ends when the board is full and no two neighbours match, so leave a corner free and plan one merge ahead.
